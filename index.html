0x01About

0x02Research Projects

architecture · compiler

RISCA

Configurable many-core VLIW RISC-V accelerator

Throughput-oriented accelerator for AI and GEMM that couples vector processing with a 2D systolic interconnect. I co-designed the processor array, distributed scratchpads, streaming datapaths, and double-buffered memory hierarchy, plus a custom LLVM backend for instruction scheduling, VLIW packetization, software pipelining, and communication-aware kernels.

N-TORC

Native Tensor Optimizer for Real-time Constraints

ML-driven design-space exploration and resource scheduling for FPGA-based scientific and real-time AI. Analytical and learned models predict latency, throughput, and utilization; an optimizer selects hardware configurations that meet execution and resource constraints. FPGA ’25 & FCCM ’25.
