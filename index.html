About

I am a Ph.D. candidate in Computer Engineering at the University of South Carolina, where I work in Prof. Jason D. Bakos's research group. I am expected to graduate in December 2026. My research is in computer architecture, with a focus on micro-architecture and compiler co-optimization for throughput-oriented workloads such as dense linear algebra (GEMM) and real-time machine learning.

My dissertation, Micro-Architecture and Compiler Co-Optimization for Maximizing the Efficiency for Throughput-Oriented Workloads, studies how processor organization, on-chip data movement, and compiler scheduling can be designed together. Central to this work is RISCA, a configurable many-core VLIW accelerator built on a custom RISC-V vector ISA with a two-dimensional systolic interconnect, along with a custom LLVM backend. I have also developed N-TORC, an ML-driven design-space exploration and resource-scheduling framework for FPGA-based real-time AI.

Before my Ph.D., I received an M.S. in Computer Engineering from California State University, Fullerton, and a B.Tech. in Electronics & Communication Engineering from IET Lucknow. I also worked as an RTL and DSP hardware intern at Pacific Microchip Corp. and HDLexpress.

Research

RISCA: A Configurable Many-Core VLIW Accelerator

A throughput-oriented accelerator for AI and GEMM workloads built on a custom RISC-V vector ISA, combining vector processing with a two-dimensional systolic interconnect. The design co-optimizes the processor array, distributed scratchpads, streaming datapaths, and a double-buffered memory hierarchy with a custom LLVM backend supporting instruction scheduling, VLIW packetization, software pipelining, hazard management, and communication-aware kernel execution. Evaluated through RTL prototypes and cycle-level simulation.

SystemVerilog · LLVM · RISC-V · cycle-level simulation · FPGA

N-TORC: Native Tensor Optimizer for Real-time Constraints

An ML-driven design-space exploration and resource-scheduling framework for FPGA-based scientific and real-time AI workloads. Analytical and machine-learning models predict latency, throughput, and resource utilization, and an optimizer selects hardware configurations that satisfy execution and resource constraints. Predictions are validated against simulation and FPGA implementation results.

HLS · ILP · performance modeling · Xilinx ZCU104 · code

Decomposition-Based Memristive Crossbar Solver

A decomposition-based method for solving linear systems on memristive crossbar arrays, paired with an FPGA-accelerated hardware implementation for evaluation.

emerging hardware · linear solvers · FPGA
